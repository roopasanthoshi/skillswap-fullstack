# SkillSwap Fullstack

A full-stack Skill Exchange Platform where users can:
- Learn new skills
- Teach skills
- Send match requests
- Book sessions
- Chat with users
- Receive notifications

## Tech Stack
Frontend:
- React
- Vite
- CSS

Backend:
- Node.js
- Express.js
- Prisma ORM
- MySQL

## Features
- Authentication
- Skill Matching
- Session Booking
- Notifications
- Real-time Chat
- User Profiles

## Database
- MySQL
- ER Diagram included
